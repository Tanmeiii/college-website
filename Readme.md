## College Website 
A modern and responsive college portal website designed to provide students with quick access to all essential college services from a single homepage. The project focuses on improving accessibility, navigation, and overall user experience compared to traditional college websites.

## Features Added
1. Chatbot 
2. Quick Access to Essential Services
3. Fully Responsive Design
4. Search Functionality
5. Improved UI/UX

## Tech Stack
- HTML 
- Tailwind CSS
- JavaScript

## Project Setup
Clone the repository
```bash
git clone https://github.com/Tanmeiii/college-website.git
```
Move into the project directory
```bash
cd college-website
```
Run website with live server
